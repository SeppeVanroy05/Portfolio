Webontwikkeling

K.V.V. Rauw.

Voor SKIL2 kregen we in semester 2 een ontwerp voor K.V.V. Rauw. Onze opdracht was om daar als groep een werkende website van te maken.

Mijn rolFrontend & backend
ContextWebontwikkeling
HTMLCSSFrontend

De opdracht

Van ontwerp naar echte website

Vak

Dit was een groepsproject voor SKIL2 in het tweede semester.

Opdracht

Het ontwerp lag al vast. Wij moesten uitzoeken hoe we dat konden bouwen.

Doel

De website moest duidelijk werken voor mensen die de club bezoeken of volgen.

Wat ik bijleerde

Wat ik ermee heb geleerd

  1. Bouwen: ik hielp het prototype omzetten naar HTML en CSS en werkte aan de opbouw van de pagina’s.
  2. Technisch: ik oefende met responsive pagina’s en met HTML en CSS die duidelijk blijven als je verder bouwt.
  3. In het team: ik leerde beter afstemmen en feedback sneller verwerken.
  4. Mijn deel: ik werkte mee aan de UI en aan de backend van de website.

Mijn deel

Mijn deel van het project

Ik werkte mee aan de voorkant én de backend. Aan de voorkant hielp ik met de pagina’s en de afwerking van het ontwerp. Aan de achterkant werkte ik mee aan de technische structuur. Daardoor begreep ik beter hoe die twee delen van een website op elkaar aansluiten.
